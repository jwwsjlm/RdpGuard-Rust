# RdpGuard v0.3.2 双语在线入口与历史日志监控设计

日期：2026-08-05

## 目标

RdpGuard v0.3.2 提供一条可直接粘贴到 Windows PowerShell 的 `irm` 命令。命令打开中英文交互菜单，用户可以安装或配置防护服务，也可以临时打开只读历史日志监控器。

后台 `RdpGuard` 服务继续常驻并执行自动封禁。`rdpguard-monitor.exe` 仅在用户手动启动时运行，不自动刷新，也不读取当前 TCP 连接。

## 用户入口

README 的首选启动方式为：

```powershell
& ([scriptblock]::Create((irm "https://github.com/jwwsjlm/RdpGuard-Rust/releases/latest/download/Install-RdpGuard-Online.ps1")))
```

在线脚本首先显示菜单，不会立即安装：

```text
RdpGuard

[1] 安装或配置防护服务
[2] 查看历史登录日志
[3] English / 中文
[0] 退出
```

手动下载 ZIP 并运行 `Install-RdpGuard.ps1` 的方式继续保留，作为离线安装和故障排查入口。

## 方案与组件边界

采用“PowerShell 在线启动菜单 + 现有本地安装器 + Rust 历史日志监控器”的分层方案。

- `Install-RdpGuard-Online.ps1`：菜单、语言选择、获取并验证正式发布包、启动选定功能、清理临时文件。
- `Install-RdpGuard.ps1`：UAC 提权、交互配置、服务安装或升级。服务管理逻辑只保留在这里。
- `rdpguard-monitor.exe`：只读历史事件、聚合结果并渲染终端界面。
- `RdpGuard` 服务：继续低占用常驻，执行失败事件检查、封禁和解封。

不把完整安装逻辑复制到在线脚本，也不额外下载 Rust 菜单启动器。这样可在下载发布包前显示菜单，并避免维护两套服务安装实现。

## 双语行为

在线入口、配置向导和历史日志界面同时提供简体中文与英文。

- 启动时检查 Windows UI culture；名称以 `zh` 开头时使用中文，否则使用英文。
- 在线主菜单按 `3` 在中文与英文间切换。
- 配置向导继承在线入口选择的语言；直接运行本地安装器时自动检测系统语言，并提供语言切换入口。
- 历史日志监控器继承在线入口选择的语言；直接运行时自动检测系统语言。
- 监控器按 `l` 在中文与英文间即时切换，不重新查询数据。
- 手动语言选择仅在当前进程链中生效，不写入服务配置或注册表；下次运行重新自动检测。

所有面向用户的菜单项、字段名、帮助、状态、警告和错误均进入集中语言资源，避免界面中混杂两种语言。IP、用户名、时间、事件 ID 和路径等原始数据不翻译。

## 发布包获取与校验

选择 `1` 或 `2` 后，在线脚本才获取最新版发布包。一次运行只下载并解压一次；用户返回主菜单后再次选择功能时复用已经验证的临时副本。

执行流程：

1. 确认运行环境为 Windows PowerShell，并启用 TLS 1.2。
2. 校验在线脚本内嵌的正式标签符合 `v<主版本>.<次版本>.<修订版本>`；稳定的 `releases/latest/download` 入口会让最新版脚本与自身标签保持一致。
3. 直接构造该标签的 GitHub Release ZIP 与 `SHA256SUMS.txt` 下载地址，避免未认证 GitHub API 限流和“latest”切换竞态。
4. 在系统临时目录下创建随机子目录并下载两个文件。
5. 严格解析校验文件，只接受目标 ZIP 对应的 64 位十六进制 SHA-256。
6. 使用 `Get-FileHash` 计算下载文件哈希并进行不区分大小写的完整比较。
7. 校验成功后解压 ZIP，确认其中存在服务程序、监控程序、默认配置和本地安装器。
8. 按菜单选择启动本地安装器或监控器，并等待其退出后返回主菜单。
9. 主菜单退出、脚本失败或被中断时，在 `finally` 中删除临时目录。

网络请求失败、Release 数据异常、文件缺失、哈希不一致或解压失败时立即停止当前操作，显示对应语言的明确错误，并且不执行未校验的发布包。

此校验可发现下载损坏或文件不匹配。脚本和校验文件均来自同一个 GitHub Release 信任边界；它不等同于代码签名，README 会如实说明这一点。

## 选项 1：安装或配置防护服务

在线脚本以所选语言启动解压后的 `Install-RdpGuard.ps1`。本地安装器将语言参数安全地传入提权后的 Windows PowerShell 进程，然后弹出 UAC。

提权成功后，安装器读取 `C:\ProgramData\RdpGuard\config.json`。如果尚未安装或配置不存在，则使用发布包内的默认配置。配置向导依次显示：

1. 检查间隔（秒）。
2. 失败统计窗口（分钟）。
3. 同一 IP 的失败次数阈值。
4. 封禁时长（分钟）。
5. IP 白名单，接受逗号分隔的 IPv4/IPv6，空输入表示保留当前值，明确输入 `clear` 或中文界面的“清空”选项才清空。

每项显示当前值、单位和程序允许范围。直接按 Enter 保留当前值；非法数字、越界数值或非法 IP 不会写入配置，而是显示原因并要求重新输入。

最后一项输入完成后立即安装或升级，不再增加二次确认步骤。安装器在修改服务前先把验证通过的新配置写入临时文件；服务安装成功后以原子替换方式更新正式配置。安装失败时保留原配置、日志、状态和已有封禁记录，并返回非零退出码。用户取消 UAC 时在线入口显示取消或失败信息并返回主菜单。

直接运行发布包中的 `Install-RdpGuard.ps1` 时也使用相同配置向导。自动化验证和维护场景保留显式非交互参数，以便使用现有配置或默认配置而不等待输入。

## 选项 2：查看历史登录日志

在线脚本运行已验证临时目录中的 `rdpguard-monitor.exe`，并传入当前语言。监控器自行请求读取 Security 日志所需的 UAC。即使尚未安装 RdpGuard 服务，也可以查看 Windows 自身保存的 RDP 登录成功与失败记录；此时没有 RdpGuard 状态文件，封禁状态显示为空。

退出监控器后返回在线主菜单。退出在线入口后删除临时 EXE，不安装服务、不创建计划任务、不修改防火墙，也不保存用户名或登录历史。

监控器保留两个页面：

- IP 历史概览：IP、登录尝试、成功、失败、RdpGuard 防护失败数、封禁状态、解封时间和最后活动时间。
- 登录事件：本地时间、成功或失败、IP、用户名和事件 ID。

删除“当前连接”页面、TCP 会话采集和相关 Windows IP Helper API 依赖。监控器启动时读取一次默认时间范围的数据；保持打开时不启动刷新计时器。

操作方式：

- `Tab` / `Shift+Tab`：切换两个页面。
- `1` / `2` / `3` / `4`：选择最近 10 分钟、1 小时、24 小时或 7 天，并按需重新读取。
- `r`：手动重新读取当前时间范围。
- `l`：在中文和英文之间即时切换。
- 方向键：滚动。
- `q` / `Esc`：退出并恢复终端状态。

Security `4624/4625` 与 RdpCoreTS `140` 继续分开统计。Security 日志不可访问时显示警告，RdpCoreTS 历史和当前封禁状态仍可显示。单个事件源仍限制最多处理 50,000 条事件。监控器不调用防火墙、封禁、解封或状态写入接口。

## 发布方式

Release 工作流除 ZIP 和 `SHA256SUMS.txt` 外，再上传 `Install-RdpGuard-Online.ps1` 作为独立附件。因此 `releases/latest/download/Install-RdpGuard-Online.ps1` 始终指向最新正式版脚本，不依赖 `main` 分支内容。

发布 ZIP 内也包含在线脚本，方便用户审查和归档。版本升级为 `0.3.2`，更新 Rust 包版本、锁文件、变更记录、测试摘要和文档，并创建 `v0.3.2` 标签触发正式发布。

## 测试策略

所有新行为先增加会因功能缺失而失败的测试，再进行实现。

在线入口覆盖：

- 系统语言自动选择、主菜单手动切换和语言参数传递。
- 选项 `1` 调用本地安装器，选项 `2` 调用临时监控器，选项 `0` 不下载任何文件。
- 同一进程只下载一次已经验证的发布包。
- 只使用固定 GitHub 仓库，严格匹配正式版本标签和资源名称。
- 哈希正确时允许执行，哈希缺失、格式错误或不一致时停止。
- 临时目录在正常退出和失败路径都会清理。
- 在线脚本存在于 Release 独立附件和 ZIP 清单。

配置向导覆盖：

- 首次安装显示默认配置，升级显示当前配置，直接回车保留当前值。
- 五项有效输入可以写入预期配置。
- 越界数字、非法 IP 和含糊的白名单清空操作被拒绝。
- UAC 参数和语言选择安全传递，不受空格、中文或单引号路径影响。
- 安装失败不覆盖原配置，成功后原子更新配置。
- 非交互模式不会等待控制台输入。

历史监控器覆盖：

- 只渲染 IP 历史概览和登录事件两个页面。
- 不再存在当前连接页面或 TCP 查询调用。
- 等待期间不会自动刷新；启动、按 `r` 和切换时间范围会重新读取且不会累计旧结果。
- 中文与英文自动选择、参数选择和按 `l` 切换均正确。
- 两页切换、滚动、窄窗口、中文显示和异常退出终端恢复继续有效。
- 未安装服务和部分日志源失败时仍能显示可用历史数据。
- 后台服务的封禁、解封及默认策略回归测试保持通过。

最终验证包括 Rust 全部测试、格式检查、Clippy、Release 构建、PowerShell 语法、工作流检查和发布资产核对。GitHub Release 完成后下载正式附件，验证一行命令入口、ZIP 哈希、文件清单以及两个 EXE 的 `0.3.2` 版本。

## 非目标

- 不建立自定义短域名或额外下载服务器。
- 不让在线脚本复制服务安装实现。
- 不增加图形配置窗口、后台 GUI、托盘程序或日志数据库。
- 不停止或削弱负责自动封禁的 `RdpGuard` 后台服务。
- 不保留当前连接页面或实时 TCP 会话监控。
- 不持久化界面语言选择。
